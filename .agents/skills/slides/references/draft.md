# 초안: `_draft.md`

장표를 만들기 전에 사용자와 무엇을 말할지 정하는 문서다. 핵심 메시지와 흐름만 적고, 마크업이나 레이아웃은 적지 않는다.

## 진행

1. **뼈대**: 사용자가 준 내용으로 발표 상황 표와 개요를 만든다. 핵심 메시지와 구간만 잡고, 정해지지 않은 곳에는 무엇이 필요한지 TODO로 적는다. 완료 조건: 모든 구간에 장표 제목이나 TODO가 하나 이상 있다.
2. **다듬기**: TODO를 사용자에게 묻고 답을 반영한다. 답하면서 새로 빈 곳이 생기면 그 자리에 TODO를 더한다. 한 번에 몇 개씩만 물어 대화를 이어 간다. 완료 조건: TODO가 없거나, 남은 TODO를 사용자가 미뤄도 된다고 했다.

## 형식

```md
| 항목 | 내용                         |
| ---- | ---------------------------- |
| 대상 | 비개발 전공 석사생 약 30명   |
| 시간 | 100분                        |
| 목적 | TODO: 끝나고 청중이 할 행동? |

`( )`는 장표에 쓰지 않고 말로 전할 내용이다. ⭐️는 핵심 장표다.

---

발표 제목

- 구간 이름 (약 10분)
  - ⭐️ 장표 제목
    - 장표에 들어갈 내용
    - (말로 전할 내용)
  - TODO: 사례 장표 하나 더. 사용자 경험담?
```

- 맨 위 표에는 발표 상황(대상, 시간, 목적 등)을 적는다.
- 들여쓰기는 구간, 장표 제목, 장표 내용 순서다. 구간 옆에 예상 시간을 적는다.
- 장표에 넣을 글은 짧게, 설명은 `( )`로 뺀다. 장표가 글로 넘치는 것을 초안에서 먼저 막는다.
- TODO에는 무엇을 정해야 하는지 질문 형태로 적는다.
